Interview Ready Together
Wired to Work: Your Brain, Your Path | Groundwork Collaborative

One page with three tabs. Learner holds the Interview Ready Roadmap. Parent holds the parent support roadmap. Outcomes puts both side by side with where answers match, where they differ and a shared plan for the week.

Files
index.html    The page with the three tabs and the Outcomes tab. This is the link to share.
learner.html  The learner roadmap. Loads inside the Learner tab.
parent.html   The parent roadmap. Loads inside the Parent tab.
Upload all three files to the same repository.

Privacy
Answers stay in the visitor's browser. Nothing is sent to a server.
Learner and parent on different devices: each person copies their code at the bottom of the Outcomes tab and the other pastes it in.

Publish with GitHub Pages
1. Create a new repository and upload all three files.
2. Go to Settings, then Pages.
3. Choose Deploy from a branch, pick main and the root folder. Save.
4. The page goes live at https://YOUR-USERNAME.github.io/YOUR-REPO/

Link straight to a tab
Add #learner, #parent or #outcomes to the end of the web address.

Embed in Kajabi
In a Kajabi page add a Custom Code block and paste an iframe that points to the page address. Give it a tall height such as 1400px.
